## 5. LED Buffer Prefix Protocol (0x80, 0x81, 0x82)

The S8 uses a segmented LED buffer. The touchstrip LEDs fall into different segments:

1.  **Prefix 0x80:** Handles LEDs 0 to ~117.
    -   Includes **Left Touchstrip** (`0x5d` to `0x75`).
2.  **Prefix 0x81:** Handles LEDs 118 to ~235.
    -   Includes **Right Touchstrip** (`0xd3` to `0xeb`).
3.  **Prefix 0x82:** Handles remaining LEDs (Mixer center, etc.).

**Crucial Note:** If the lights are not turning on, ensure the buffer sent with prefix `0x81` is long enough to reach index `0xeb` (at least 236 bytes including prefix).
